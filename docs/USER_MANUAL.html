1. Introduction, Heritage & Design Philosophy

NuTrackN (the flagship analysis environment of the NuGASP suite) is an interactive, high-performance nuclear spectroscopy application designed for experimental nuclear physicists, gamma-ray spectroscopists, and radiation detection laboratories.

1.1 The Heritage of Xtrackn & GASPware

For decades, the classic Fortran/C software Xtrackn and the larger GASPware suite (developed across European and international heavy-ion and gamma-ray facilities like GASP, AGATA, and EUROBALL) served as the gold standard for high-throughput gamma-gamma matrix gating and spectrum analysis. Experimentalists developed deep muscle memory for its single-character and two-character command strings.

NuTrackN preserves 100% of authentic Xtrack keyboard commands, while re-engineering the underlying platform into modern C++17 with: - CERN ROOT Graphics Engine: Sub-millisecond rendering of high-statistics histograms and logarithmic axes. - Modern Qt5 User Interface: High-DPI screen support, responsive dialogs, live parameter tables, and curated dark/light themes. - 2D Matrix Coincidence Viewer: Fast slicing and projection of multi-gigabyte γ-γ coincidence matrices (.cmat). - Autonomous Standalone Deployment: 1-click execution without requiring users to configure compiler paths or install CERN ROOT manually. - Run-by-Run Drift Alignment: Automated in-beam gain tracking across hundreds of acquisition runs.

NOTE

Operational Model & Terminal Notice:
NuTrackN keyboard commands are executed directly on the interactive spectrum canvas (hotkeys). Due to the current focus on user-friendly dialog windows, interactive parameter tables, and graphical workflows, program operation through the terminal (either the system terminal / stdin or the in-built bottom console) is not currently functional for command input. The in-built bottom console serves exclusively as an output log for calculation reports, marker moment summaries, and fit parameters. Terminal-driven command execution and headless batch processing with no GUI will be the topic of a later upgrade.

  • Peak Fitting & Multiplet Deconvolution: Extracting and propagating full Minuit parameter covariance matrices ($\text{cov}(A, \mu, \sigma)$) and asymmetric confidence intervals (MINOS) to avoid underestimating peak area errors under heavy baseline coupling.
  • Energy & Efficiency Calibrations: Seamless propagation of polynomial parameter covariances ($\text{cov}(a_i, a_j)$), literature decay standard uncertainties, and source half-life corrections directly into calibrated energy readouts ($E \pm \sigma_E$) and detector efficiency curves.

  • Rudimentary RDDS Fitting: Recoil Distance Doppler Shift (plunger) lifetime measurements and shifted/unshifted intensity decay curve fitting.

1.5 The NuGASP Ecosystem Scope

The NuGASP suite is conceived as the modern C++17 / Qt5 successor to the offline analysis ecosystem of GASPware. Its overarching goal is to modernize and consolidate the classic tools developed for the GASP spectrometer—including spectrum visualization (xtrackn), 2D matrix projection and slicing (cmat), spectrum arithmetic and gain-matched addition (sadd), efficiency parameterization (effi), initial polynomial calibrations (precal), and run-by-run drift minimization (trackfit)—into a unified, high-performance computing environment.

The sole deliberate exception to this scope is gsort (the raw event-sorting and list-mode reconstruction engine). Due to its specialized hardware-level data unpacking, real-time trigger handling, and online acquisition requirements, gsort remains an independent standalone program outside NuTrackN.

2.5 First Spectrum Walkthrough in 60 Seconds

  1. Launch nutrackn.
  2. Press N (or click the spectrum open button) and select your spectrum file (e.g. 152Eu_sample.spe).
  3. Press L to toggle between Linear and Logarithmic scale.
  4. Hover the cursor over a photopeak; the Live Peak Inspector Box in the upper right dynamically displays centroid, channel, counts, and local FWHM.

3. Data Input, Output (I/O) & File Management

3.1 Supported Nuclear Spectroscopy Formats

NuTrackN automatically detects and parses all standard nuclear physics data formats: - Ortec Maestro (.spe, .chn): Standard multichannel analyzer ASCII and binary records with header timing and live/real time tags. - Canberra Formats & Generic ASCII (.txt, .dat, .csv): Single-column counts or two-column $(Channel, Counts)$ with space, tab, or comma separation. - Radware (.spe): Integer and floating-point Radware spectrum buffers. - CERN ROOT Histograms (.root): 1D histograms (TH1D, TH1F, TH1I) and 2D matrices (TH2D). - Compressed Coincidence Matrices (.cmat, .mat): GASPware symmetrized and raw 2D gamma coincidence matrices.

3.2 Loading Spectra & Multi-Buffer Overlays (Buffers 1–9)

NuTrackN supports multi-pad canvas grids alongside multi-spectrum overlays on any individual pad: - Multi-Pad Grid Layout: - Use Ctrl + → to add a new display column and Ctrl + ← to remove a column. - Use Ctrl + ↑ and Ctrl + ↓ to add or remove display rows. - Click inside any sub-window to make it the active pad (highlighted by a colored frame border). - Multi-Buffer Overlays & Stepping: - Up to 9 spectra can be overlaid within the same pad (HijC overlay stack), each rendered with its distinct theme palette color. - Use N / N+ / *1 and N- / *2 to step forward or backward through spectra/detectors, and *3 (R+ / NR) or *4 (R- / PR) to step forward or backward across experimental runs. - (Note: On the canvas keyboard, single digits 0–9 trigger stored numeric macros; see Section 10.2). - Cross-Pad & Overlay Synchronization: - Use SX / SY to propagate the active pad's horizontal (X) or vertical (Y) scale and linear/logarithmic mode across all visible sub-canvases and their overlaid spectra.

3.3 Modern File Dialog (NuFileDialog) & Live Previews

NuTrackN features an embedded high-speed file browser (NuFileDialog): - Live Spectrum Mini-Preview: Click any spectrum file to inspect its raw channel count and shape in real time before opening. - Fast Navigation Bookmarks: Quick access to experiment data directories, USB mount points, and home directories. - Format Filter Filtering: Dynamic switching between .spe, .chn, .root, and all ASCII variations.

4. Canvas Navigation, Scaling & Real-Time HUD

4.1 Display Scales & Vertical Adjustments

  • L: Toggle between Linear and Logarithmic Y-axis display (automatically clamping log minimum to 0.5 counts and computing peak headroom across both the primary histogram and any overlaid spectra).
  • U / D: Vertically expand or compress the active histogram counts.
  • FO: Set the vertical axis maximum (Y-Max) directly to the count level under the cursor.
  • FU: Set the vertical axis minimum (Y-Min) directly to the count level under the cursor.
  • MZ: Draw a reference baseline line at zero counts.

4.2 Horizontal Panning & Zooming

  • E (Expand): Zooms the horizontal axis to fit the region between the two most recently placed Spacebar markers.
  • X: Centers the view around the current cursor location with 2× magnification.
  • < / >: Pan the visible spectrum window 75% to the left or right.
  • FF (or FS): Full display reset (both horizontal and vertical axes auto-scale to full dataset, equivalent to FX + FY).
  • FX / FY: Reset only the horizontal (energy/channel) or vertical (counts, with configurable 10% linear / 30% log headroom above the highest visible peak across all overlays) scale.
  • =: Redraw and refresh canvas.

4.3 Mouse Navigation & Interactive Marker Dragging

  • Rubber-band Box Zoom: Left-click and drag a rectangular region over any spectrum feature to zoom directly into that bounding box.
  • Interactive Marker Dragging: Left-click and drag any active marker along the spectrum curve to fine-tune integration or fitting limits interactively.
  • Clickable Axis Labels: Left-click or right-click (with optional Ctrl modifier for fine/coarse stepping) the X Min, X Max, Y Min, or Y Max readout boxes on the top status header bar to adjust limits in discrete steps.

4.4 Real-Time HUD Peak Inspector

Located in the upper right quadrant of the spectrum canvas, the HUD Inspector computes real-time statistics for whatever feature the cursor is hovering over: - Cursor Energy & Channel: Exact interpolated calibration coordinate. - Counts / Bin: Discrete histogram content $C(ch)$. - Local Centroid: Moment-calculated peak center within cursor proximity: $$\langle ch \rangle = \frac{\sum_{i \in \text{win}} i \cdot C_i}{\sum_{i \in \text{win}} C_i}$$ - Local FWHM: Instantaneous full-width at half-maximum derived from local variance.

5. Peak Integration & Region of Interest (ROI) Analysis

5.1 Setting Boundary Markers

  • Spacebar: Place generic analysis marker at mouse pointer.
  • B: Place Background marker (Blue).
  • I: Place Integration boundary marker (Yellow).
  • [ and ]: Convenient left and right boundary placement.

5.2 Mathematical Formulation of Gross & Net Peak Area

Given a photopeak bounded by a pair of integration markers ($ch_{min}$ and $ch_{max}$), let $y_i$ denote the bin content at channel center $x_i$:

  1. Gross Integrated Area ($G$): Calculated by the CI command without baseline subtraction: $$G = \sum_{i = ch_{min}}^{ch_{max}} y_i$$

  2. Least-Squares Linear Background Estimation (CB / CJ): Background markers (B) are placed in consecutive pairs $[b_{1,\text{left}}, b_{1,\text{right}}], [b_{2,\text{left}}, b_{2,\text{right}}], \dots$ defining arbitrary background intervals on either side of the peak(s). Across all $N_{bg}$ channels enclosed by these background marker pairs, NuTrackN performs ordinary least-squares (OLS) linear regression to determine the best-fit baseline: $$B(x) = m \cdot x + c$$ where the slope $m$ and intercept $c$ are evaluated from the background sample means $(\bar{x}, \bar{y})$: $$m = \frac{\sum_{k=1}^{N_{bg}} (x_k - \bar{x})(y_k - \bar{y})}{\sum_{k=1}^{N_{bg}} (x_k - \bar{x})^2}, \quad c = \bar{y} - m \cdot \bar{x}$$

  3. Net Peak Area ($N$): Calculated by the CJ command (or automatically at the cursor via AJ) by subtracting the interpolated linear background $b_i = m \cdot x_i + c$ bin-by-bin across each pair of integration markers: $$N \equiv M_0 = \sum_{i = ch_{min}}^{ch_{max}} (y_i - b_i) = \sum_{i = ch_{min}}^{ch_{max}} y_{\text{net}, i}$$

5.3 Counting Statistics, Statistical Moments & Error Propagation

NuTrackN implements the authentic Xtrackn / GASPware statistical moment and variance propagation algorithm relative to the interval midpoint $x_{\text{mid}} = \frac{1}{2}(ch_{min} + ch_{max})$. Let $w_i = x_i - x_{\text{mid}}$ be the centered channel offset:

  1. Net Moments ($M_0, M_1, M_2$) and Variance Moments ($D_0, D_1, D_2, D_4$): For each bin $i$ in the integration window, the gross Poisson variance is $\sigma^2(y_i) = \max(y_i, 1)$ and the background variance contribution is $\sigma^2(b_i) = \max(b_i, 0)$, yielding a per-bin net variance $v_i = \max(y_i, 1) + \max(b_i, 0)$. The moments are accumulated as: $$M_k = \sum_{i = ch_{min}}^{ch_{max}} y_{\text{net}, i} \, w_i^k \quad (k = 0, 1, 2), \qquad D_n = \sum_{i = ch_{min}}^{ch_{max}} v_i \, w_i^n \quad (n = 0, 1, 2, 4)$$

  2. Net Area Uncertainty ($\sigma_N$): $$\sigma_N = \sqrt{D_0} = \sqrt{\sum_{i = ch_{min}}^{ch_{max}} \left(\max(y_i, 1) + \max(b_i, 0)\right)}$$

  3. First-Moment Centroid ($Ch_0$) & Uncertainty ($\sigma_{Ch_0}$): With $\delta x = M_1 / M_0$, the background-subtracted centroid and its propagated variance are: $$Ch_0 = x_{\text{mid}} + \delta x, \qquad \sigma^2(Ch_0) = \frac{D_2 - 2\,\delta x\,D_1 + (\delta x)^2 D_0}{M_0^2}$$

  4. Second-Moment Peak Width (FWHM) & 4th-Moment Error Propagation: From the central variance $s^2 = (M_2 / M_0) - (\delta x)^2$, the statistical FWHM and its uncertainty are evaluated as: $$\text{FWHM} = 2\sqrt{2\ln 2}\, s \approx 2.354820 \, \sqrt{s^2}$$ $$\sigma(\text{FWHM}) = \frac{\text{FWHM}}{2 s^2} \sqrt{4(\delta x)^2 \sigma^2(Ch_0) + \frac{D_4}{M_0^2} - \frac{2 M_2 D_2}{M_0^3} + \frac{M_2^2 D_0}{M_0^4}}$$

  5. Spectroscopic Bracketed Uncertainty Formatting: Results printed to the output console and terminal log use standard nuclear spectroscopy parenthetical notation for the least significant digits—for example, an energy of 1332.49(5) keV denotes $1332.49 \pm 0.05\text{ keV}$, and an area of 14520(135) denotes $14520 \pm 135\text{ counts}$.

6. Standard Energy & Efficiency Calibration

6.1 Calibration Physics Formulation

Spectroscopy channel numbers ($ch$) are mapped to physical gamma-ray energies ($E$, in keV) using a polynomial calibration model: $$E(ch) = a_0 + a_1 \cdot ch + a_2 \cdot ch^2$$ where: - $a_0$: Electronic zero offset / ADC intercept (in keV). - $a_1$: Primary gain / dispersion slope (in keV/channel). - $a_2$: Second-order non-linearity parameter (typically $|a_2| < 10^{-6}\text{ keV/ch}^2$).

The detector energy resolution (Full Width at Half Maximum) is parameterized as a function of energy: $$\text{FWHM}^2(E) = w_0 + w_1 \cdot E + w_2 \cdot E^2$$ accounting for electronic noise ($w_0$), charge collection statistics / Fano factor ($w_1$), and incomplete charge collection ($w_2$).

6.2 Fast 2-Point Calibration Routine (K)

For quick experimental checks during setup: 1. Place markers on two known photopeaks (e.g., the 511.0 keV positron annihilation line and 1274.5 keV $^{22}\text{Na}$ line). 2. Press K and enter the two literature energies when prompted. 3. NuTrackN calculates $a_0$ and $a_1$ instantaneously and updates the canvas axis readout to keV.

6.3 Full Polynomial Calibration Dialog (DK)

Select polynomial degree (Linear: 1, Quadratic: 2). 3. Review the parameter correlation matrix and fit residuals $\Delta E_i = E_{lit, i} - E_{calc, i}$. 5. Click Save Calibration to export to an ASCII .mcal file.

6.5 Detector Full-Energy Peak Efficiency Calibration (DE)

The absolute full-energy peak efficiency at energy $E_γ$ is determined from standard calibrated radioactive sources: $$\epsilon(E_γ) = \frac{N_{net}(E_γ)}{A_{act} \cdot I_γ \cdot t_{live}}$$ where: - $N_{net}$: Measured net peak counts. - $A_{act}$: Source activity at the measurement epoch, corrected for radioactive decay: $$A_{act}(t) = A_0 \cdot \exp\left( -\frac{\ln 2 \cdot \Delta t}{T_{1/2}} \right)$$ - $I_γ$: Absolute emission probability per decay. - $t_{live}$: Measurement live time (seconds).

Press DE to open the Efficiency Calibration Dialog: - Select the fitting model: 1. Log-Log Polynomial: $$\ln \epsilon = \sum_{k=0}^n c_k (\ln E)^k$$ 2. Dual-Regime Power Law: Combining low-energy absorption and high-energy pair production regimes. - Click Apply to bind the efficiency calibration to the active session. Unknown sample activities are then calculated automatically from measured peak areas.

7. Advanced Peak Fitting & Multiplet Deconvolution

7.1 Physical Peak Models (Gaussian & Low-Energy Tail)

In semiconductor gamma detectors (HPGe, Si(Li)), incomplete charge collection due to crystal impurities or radiation damage causes low-energy peak tailing. NuTrackN models photopeaks with two primary response functions:

  1. Symmetric Gaussian Model: $$g(x) = A \cdot \exp\left( -\frac{1}{2}\left(\frac{x - x_0}{\sigma}\right)^2 \right)$$ where $A$ is peak amplitude, $x_0$ is centroid channel, and $\sigma$ is Gaussian dispersion ($\text{FWHM} = 2.35482 \cdot \sigma$).

  2. Skewed Gaussian with Exponential Low-Energy Tail: $$f(x) = \begin{cases} A \cdot \exp\left( -\frac{(x - x_0)^2}{2\sigma^2} \right) & \text{for } x \ge x_0 - t \cdot \sigma \\ A \cdot \exp\left( \frac{t^2}{2} + \frac{t(x - x_0)}{\sigma} \right) & \text{for } x < x_0 - t \cdot \sigma \end{cases}$$ where $t > 0$ specifies the join point in units of standard deviation $\sigma$.

7.2 Step Backgrounds: ERFC Compton Plateau & Median Sidebands

Beneath every gamma photopeak lies a step in the background caused by multiple Compton scattering of photons that escape the detector before depositing full energy. NuTrackN models this background using an analytic complementary error function ($\text{erfc}$):

$$B(x) = m \cdot x + c + S \cdot \frac{1}{2} \text{erfc}\left( \frac{x - x_0}{\sqrt{2}\sigma} \right)$$ where: - $m$: Background slope across the ROI. - $c$: Baseline offset. - $S$: Compton step amplitude.

7.3 Poisson Maximum Likelihood Estimation vs. Least-Squares

Standard $\chi^2$ minimizations assume Gaussian-distributed count errors ($\sigma_i = \sqrt{C_i}$). For low-statistics peaks ($C_i < 20$ counts/bin), this approximation fails and produces a systematic negative bias in peak area.

NuTrackN implements Poisson Maximum Likelihood Estimation (ROOT option "L" with "I" bin integration). Given measured bin counts $y_i$ and model expectation $\mu_i(p)$: $$\ln L(p) = \sum_{i=1}^M \left[ y_i \ln \mu_i(p) - \mu_i(p) - \ln(y_i!) \right]$$ Minimizing the objective function $-2 \ln L$ guarantees unbiased centroid and area convergence even on weak peaks with zero-count bins. If likelihood optimization fails due to extreme background conditions, the engine automatically falls back to Minuit-improved least-squares ("Q M R S").

7.4 Dynamic Peak Extent, Valley Search & Physical Capping

When fitting peaks in congested regions: - Outward Valley Search: Starting from the centroid, the fitting routine searches left and right for local minima (valleys). - Dynamic Extent Window: The fitting boundaries automatically contract if an adjacent doublet peak is detected, preventing the baseline from absorbing neighboring photopeaks.

7.5 Multiplet Deconvolution & Parameter Linking/Locking

To deconvolute overlapping multiplets: 1. Place Fit Range markers (R) enclosing the entire cluster. 2. Place centroid markers (G or +) on each visible apex. 3. Press CV to execute the multi-component fit. 4. Open the Fit Parameters Dialog (DG) to configure constraints: - Link Widths: Enforce identical $\sigma$ across all peaks in the multiplet ($\sigma_1 = \sigma_2 = \dots = \sigma_k$). - Lock Centroid / Width: Fix specific parameters to known values (e.g., from literature line separation) while allowing peak areas to float freely.

7.6 Goodness of Fit & Residuals Inspection

Upon convergence, NuTrackN computes the reduced chi-square: $$\chi^2 / \text{NDF} = \frac{1}{M - K} \sum_{i=1}^M \frac{(y_i - \mu_i)^2}{\mu_i}$$ where $M$ is the number of fitted channels and $K$ is the number of free parameters. The interactive parameter table highlights fits with $\chi^2/\text{NDF} \le 1.8$ in green, while elevated values indicate unresolved multiplets or non-standard baseline behavior.

8.6 High-Statistics Chunking & Hardware Jump-Aware Smoothing

When analyzing low-cross-section transitions or short beam runs, individual run spectra may lack sufficient counting statistics for stable peak fitting. NuTrackN provides a two-stage Pass 2 refinement system:

1. Hardware Jump Boundary Detection

Hardware gain jumps (e.g., preamplifier resetting, high-voltage adjustments, or NIM crate thermal steps) produce abrupt gain discontinuities. NuTrackN automatically identifies these steps: - Cut (%): Configurable threshold (default 0.035 %, corresponding to $|\Delta a_1| / a_1 \ge 0.00035$ or $\sim 1.4$ channels at channel 4000). - Runs separated by jumps greater than this cut are partitioned into distinct, isolated segments. Neither chunking nor smoothing is permitted to cross jump boundaries, preserving true physical gain shifts.

2. Pass 2 Raw Spectrum Chunking

Clicking ⚡ Re-Calibrate with Chunks groups consecutive runs within each jump-bounded segment into chunks of size $K$ (configured via Chunk: [ K ] runs): - Raw Histogram Summing: The engine accumulates raw spectra channel-by-channel across the chunk runs, multiplying peak statistics by $K$ and reducing statistical centroid variance by $\sqrt{K}$. - Chunk Max $\chi^2$ Cutoff: Because Poisson uncertainty $\sigma = \sqrt{N}$ increases the reduced $\chi^2/\text{ndf}$ for high-count composites (e.g. from $\sim 2$ up to $\sim 15 - 30$ despite sub-channel centroid accuracy), a dedicated Chunk Max $\chi^2$ spinbox (default 25.0) prevents false rejections of high-statistics chunk fits. - Linear Center-Interpolation: Fitted calibration parameters from chunk centers are smoothly interpolated across the constituent runs, eliminating non-physical staircase steps. - Chunk Intervention: If a chunk composite fit fails or exceeds the cutoff, its runs are flagged as INTERVENE (orange). Double-clicking any constituent run opens the intervention dialog directly on the composite chunk spectrum, and applying or force-accepting the fit synchronously calibrates all runs in that chunk.

3. Moving Window Smoothing (Smooth a1:)

To eliminate residual statistical jitter while preserving the underlying continuous gain drift: - Check Smooth a1: in the inspector bar and select the moving average Window (e.g., 3 to 31 runs, odd). - With Preserve Jumps enabled, smoothing applies a Gaussian-weighted moving filter strictly within continuous hardware segments, stopping dead at jump boundaries. - The drift inspection canvas live-renders both the raw Pass 1 gain points (faint green) and the finalized/smoothed chunk trajectory (solid gold curve). Both .cal and .ucal exports automatically incorporate the smoothed parameters when this option is checked.

9. 2D Coincidence Matrix Analysis

9.1 Foundations of Gamma-Gamma Coincidence Matrices

In experimental nuclear decay and heavy-ion reaction studies, detector arrays record pairs of gamma rays detected in prompt coincidence ($\Delta t < 20\text{ ns}$). These events form a 2D matrix $M(E_1, E_2)$ where each cell $(i, j)$ represents the number of coincidence events between channel $i$ and channel $j$.

NuTrackN reads both raw and symmetrized compressed coincidence matrices (.cmat and .mat formats).

9.2 Inspecting Matrices (Q & MatrixDialog)

  • Click the CM button or press DQ to open the 2D Matrix Inspector.

9.3 Coincidence Gating (CW) & Background Subtraction (DW)

To isolate gamma cascades feeding or depopulating a specific nuclear level: 1. Place coincidence Gate Markers (W) defining the energy window $[E_{gate\_min}, E_{gate\_max}]$ across the gating photopeak. 2. Press CW (Coincidence Window cut): NuTrackN slices through the 2D matrix: $$S_{gate}(E_2) = \sum_{E_1 = E_{gate\_min}}^{E_{gate\_max}} M(E_1, E_2)$$ 3. Background-Subtracted Gated Spectra (DW): Place background slices on both sides of the gating peak. NuTrackN computes the net coincidence spectrum: $$S_{net}(E_2) = S_{gate}(E_2) - \frac{A_{gate}}{A_{bg}} \cdot S_{bg}(E_2)$$ completely eliminating random Compton coincidences and cleanly revealing the true coincident cascade.

14.3 Coordinate System & Binning Conventions (0-Indexed Channels)

NuTrackN strictly enforces 0-indexed channel numbering across all data structures, canvas cursors, HUD inspector readouts, and export routines: - Channel 0 corresponds to the interval $[-0.5, +0.5)$ in continuous coordinate space. - A 4096-channel spectrum spans channels $0$ through $4095$ (inclusive). - When converting channels to energy: $$E(ch) = a_0 + a_1 \cdot ch + a_2 \cdot ch^2$$ the channel value $ch$ evaluated is identical to the discrete MCA bin index.
